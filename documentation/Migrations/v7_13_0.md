# How to migrate to AdswizzSDK v7.13.0+

Version 7.13.0 of the **_AdswizzSDK_** introduces an important change that requires updates to your integration: all API interfaces that previously used `Double` or `Long` for time-related parameters have been updated to use Kotlin’s `Duration` type.

This guide will help you upgrade your application to v7.13.0 with minimal effort. The sections below outline the changes introduced in this release. For the complete list of changes, please also refer to the [Changelog](Android/CHANGELOG.md).


## 1. `AdPlayer` interface
Parameter or return types `Double` or `Double?` have been replaced by `Duration` or `Duration?`.

Before v7.13.0:
```kotlin
	 
	 abstract fun getCurrentTime(): Double 
	 abstract fun getDuration(): Double?
	 abstract fun seekTo(position: Double)

```

Since v7.13.0:
```kotlin

	 abstract fun getCurrentTime(): Duration 
	 abstract fun getDuration(): Duration?
	 abstract fun seekTo(position: Duration)

```

## 2. `AdswizzAdRequest` class
Change `Long?` parameter to `Duration?`.

Before v7.13.0:
```kotlin

	fun withDuration(duration: Long?) 

```

Since v7.13.0:
```kotlin

	fun withDuration(duration: Duration?) 

```
