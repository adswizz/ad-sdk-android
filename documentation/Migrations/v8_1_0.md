# How to migrate to AdswizzSDK v8.1.0+

Version 8.1.0 of the **_AdswizzSDK_** introduces change that require updates to your integration regarding the `AdPlayer.MetadataItem`. Starting with 8.1.+, the `AdPlayer.MetadataItem` nested data class was moved to new `AdMetadataItem` standalone class.
```kotlin
/**
 * MetadataItem encapsulates one key-value item used in the onMetadata callback
 *  @property key metadata key
 *  @property value metadata value. All values are encoded as String type
 *
 */
data class AdMetadataItem(val key: String, val value: String)

```

This guide will help you upgrade your application to v8.1.0 with minimal effort. The sections below outline the changes introduced in this release. For the complete list of changes, please also refer to the [Changelog](Android/CHANGELOG.md).

### 1. `AdPlayer.Listener` interface

Changed the signature of `AdPlayer.Listener.onMetadata(metadataList: List<MetadataItem>)` to `AdPlayer.Listener.onMetadata(metadataList: List<AdMetadataItem>)`

Before v8.1.0:
```kotlin
interface AdPlayer {
    ....
    interface Listener {
        ...
        fun onMetadata(metadataList: List<MetadataItem>)
    }
}
```

Since v8.1.0:
```kotlin
interface AdPlayer {
    ....
    interface Listener {
        ...
        fun onMetadata(metadataList: List<MetadataItem>)
    }
}
```

Example usage:
```kotlin

import com.adswizz.common.AdPlayer
import com.adswizz.common.AdMetadataItem

class YourAdPlayerImplementation: AdPlayer, Player.Listener {
    ...
    private var listenerList: ConcurrentLinkedQueue<AdPlayer.Listener> = ConcurrentLinkedQueue()
    
    override fun onMetadata(metadata: Metadata) {
        val metadataList = mutableListOf<AdMetadataItem>()
        for (i in 0 until metadata.length()) {
            when (val entry = metadata.get(i)) {
                is IcyInfo -> {
                    if (entry.title != null) {
                        metadataList.add(AdMetadataItem("title", entry.title ?: ""))
                    }
                    if (entry.url != null) {
                        metadataList.add(AdMetadataItem("url", entry.url ?: ""))
                    }
                }
                is TextInformationFrame -> {
                    if (entry.values[0].isNotEmpty()) {
                        metadataList.add(AdMetadataItem("value", entry.values[0]))
                    }
                    if (!entry.description.isNullOrEmpty()) {
                        metadataList.add(
                            AdMetadataItem(
                                "description",
                                entry.description.toString()
                            )
                        )
                    }
                }
                is UrlLinkFrame -> {
                    // do nothing
                }
                is PrivFrame -> {
                    // do nothing
                }
                is GeobFrame -> {
                    // do nothing
                }
                is ApicFrame -> {
                    if (!entry.description.isNullOrEmpty()) {
                        metadataList.add(
                            AdMetadataItem(
                                "description",
                                entry.description.toString()
                            )
                        )
                    }
                    if (entry.mimeType.isNotEmpty()) {
                        metadataList.add(
                            AdMetadataItem(
                                "description",
                                entry.mimeType
                            )
                        )
                    }
                }
                is CommentFrame -> {
                    if (entry.text.isNotEmpty()) {
                        metadataList.add(AdMetadataItem("text", entry.text))
                    }
                }
                is Id3Frame -> {
                    // do nothing
                }
                is EventMessage -> {
                    // do nothing
                }
            }
        }
        listenerList.forEach { it.onMetadata(metadataList) }
        
        // OR use the "toAdMetadataList" extension function in order to parse the metadata

        // listenerList.forEach { it.onMetadata(metadata.toAdMetadataList()) }
        
    }
}
```

### 2. `AdStreamManager.Listener` class
Changed the signature of `AdStreamManager.Listener.onMetadataChanged(adStreamManager: AdStreamManager, metadataItem: MetadataItem)` to `AdStreamManager.Listener.onMetadataChanged(adStreamManager: AdStreamManager, metadataItem: AdMetadataItem)`

Before v8.0.0:
```kotlin
abstract class AdStreamManager {
    ...
    interface Listener {
        ...
        fun onMetadataChanged(adStreamManager: AdStreamManager, metadataItem: AdPlayer.MetadataItem)
    }
}
```

Since v8.0.0:
```kotlin
abstract class AdStreamManager {
    ...
    interface Listener {
        ...
        fun onMetadataChanged(adStreamManager: AdStreamManager, metadataItem: AdMetadataItem) = Unit
    }
}
```
Example usage:
```kotlin
import com.ad.core.streaming.AdStreamManager
import com.adswizz.common.AdMetadataItem

val adStreamListener = object : AdStreamManager.Listener {
    override fun adBreakEnded(adStreamManager: AdStreamManager, adBaseManager: AdBaseManager) {
        // you will get notified when adBreakEnded
    }

    override fun adBreakStarted(adStreamManager: AdStreamManager, adBaseManager: AdBaseManager) {
        // you will get notified when adBreakStarted
    }

    override fun onMetadataChanged(adStreamManager: AdStreamManager, metadataItem: AdMetadataItem) {
        // you will get notified when stream metadata has changed here
    }
}
```

> **Note**
> Since 8.1.0 version, the `AdStreamManager.Listener`'s methods will have default empty implementation permitting selectively overrides. For more details, please visit the [Server Side Insertion](Android/SDKAndroid/ServerSideInsertion.md) page.
