# How to migrate to AdswizzSDK v7.8.0+

The **_AdswizzSDK_** v7.8.0 release contains architectural changes behind the scenes. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.8.0 and later**. For the latest changes, please visit the [Changelog](Android/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** v7.8.0 has brought support for [AdswizzSDKPinpointAnalytics](Android/PinpointAnalytics/AdswizzSDKPinpointAnalytics) framework.
