# How to migrate to AdswizzSDK v7.8.0+

The **_AdswizzSDK_** v7.8.0 release contains architectural changes behind the scenes. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.8.0 and later**. For the latest changes, please visit the [Changelog](/Android/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** v7.8.0 has brought support for [AdswizzSDKPinpointAnalytics](/Android/PinpointAnalytics/AdswizzSDKPinpointAnalytics) framework.

_NOTE_: The `com.adswizz:adswizz-sdk-protobufJava` artifact which uses full protobuf java library is not longer maintained.
The latest release of this flavour is: `com.adswizz:adswizz-sdk-protobufJava:7.7.25`


### Prerequisites
* Kotlin version bumped to 1.7.21
* coroutines version bumped to 1.6.4
* Android Studio Giraffe | 2022.3.1 (or later)
* (AGP) Gradle Build Tools 8.0.2 (or later) this also implies a minimum version of Gradle Wrapper 8.0

### Library dependencies updates
In order to have up and running all functionalities of **_AdswizzSDK_** we needed to update our dependencies also. Those main dependencies updates are:
* androidx.room:room-runtime 2.3.0 -> 2.5.2
* androidx.work:work-runtime-ktx 2.5.0 -> 2.8.1
* androidx.appcompat:appcompat 1.3.1 -> 1.6.1
* com.squareup.moshi:moshi 1.12.0 -> 1.14.0
* com.google.protobuf:protobuf-javalite 3.11.0 -> 3.23.3
* com.google.android.material:material 1.4.0 -> 1.9.0
* replaced androidx.lifecycle:lifecycle-extensions -> androidx.lifecycle:lifecycle-process

### Android SDK compile & target API version 33
The **_AdswizzSDK_** v7.8.0 was compiled with version 33, so it is aware of Android API 33 and it can handle changes for: 
* Permissions eg: POST_NOTIFICATION, BLUETOOTH_SCAN & BLUETOOTH_CONNECT
* exported flags for Broadcast Receivers

### New permissions in AndroidManifest
The **_AdswizzSDK_** can deliver user notifications (if granted and configured properly) through its ad interactivities, so your application AndroidManifest.xml may need some modification like follows.

```xml

    <!-- used for decoration. Used in sonar tracking endpoint for the gps location. Used in analytics when sending the batch to the server -->
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
    <!-- used for polling and profile sonar endpoints to get the microphone status. Used for speech recognition on both phone and wear -->
    <uses-permission android:name="android.permission.RECORD_AUDIO" />
    <!-- used in interactivity for the download file and download pass file actions -->
    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
        android:maxSdkVersion="32" />
    <!-- used in interactivity call action -->
    <uses-permission android:name="android.permission.CALL_PHONE" />
    <!-- used during creative selection based on network conditions. Used in interactivity call action. used for detecting network state and sending to mercury analytics -->
    <uses-permission android:name="android.permission.READ_PHONE_STATE" />
    <!-- used during creative selection based on network conditions. used for detecting network state and sending to mercury analytics -->
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
    <!-- used for sonar profile and polling endpoints when it populates the wifi info -->
    <uses-permission android:name="android.permission.ACCESS_WIFI_STATE"/>
    <!-- used for decoration. Used in sonar tracking endpoint for the gps location -->
    <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
    <!-- we use it in sonar to add the list of installed apps and bundleVersion to the profile endpoint -->
    <!-- Required for 31+. -->
    <uses-permission android:name="com.google.android.gms.permission.AD_ID"/>

    <!-- Required for 33+. -->
    <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />


    <!-- Request legacy Bluetooth permissions on older devices. -->
    <uses-permission android:name="android.permission.BLUETOOTH"
        android:maxSdkVersion="30" />

    <uses-permission android:name="android.permission.BLUETOOTH_SCAN" />
    <uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />


    <!-- used for sonar polling endpoint where it sends the list of user activities -->
    <!-- Required for 28 and below. -->
    <uses-permission android:name="com.google.android.gms.permission.ACTIVITY_RECOGNITION" />
    <!-- Required for 29+. -->
    <uses-permission android:name="android.permission.ACTIVITY_RECOGNITION" />


```
