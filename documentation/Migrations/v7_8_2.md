# How to migrate to AdswizzSDK v7.8.2+

The **_AdswizzSDK_** v7.8.2 release contains changes regarding how listeners are kept internally. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.8.2 and later**. For the latest changes, please visit the [Changelog](Android/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** v7.8.2+ keeps strong references for the given listeners, so when a listener is no longer needed it should be cleared accordingly by calling `removeListener(listener: Listener)` or `setListener(null)` depending on each case.
Those changes includes the following classes/interfaces: `AdBaseManager`, `AdManager`, `AdStreamManager`, `AdPodcastManager`, `AdVideoView`. Check the usage described in the following scenarios.


### AdManagerListener usage

```kotlin

        var adManager: AdManager? = null

        val adManagerListener = object : AdManagerListener {
           ...
        }
	
	    ...

        adManager?.setListener(adManagerListener)
       
	    ...

        // this is important starting v7.8.2
        // make sure you remove adapter when no longer needed 
        adManager?.removeAdManagerListener()


```

### AdStreamManager.Listener usage

```kotlin

     
        val adStreamManagerListener = object : AdStreamManager.Listener{
           ...

        }
        val adStreamManager = AdswizzAdStreamManager()
        adStreamManager.addListener(adStreamManagerListener)

	    ...

        // this is important starting v7.8.2
        // make sure you remove adapter when no longer needed
        adStreamManager.removeListener(adStreamManagerListener)

```
