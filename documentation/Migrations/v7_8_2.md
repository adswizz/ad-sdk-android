# How to migrate to AdswizzSDK v7.8.2+

The **_AdswizzSDK_** v7.8.2 release contains changes regarding how listeners are kept internally. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.8.2 and later**. For the latest changes, please visit the [Changelog](Android/CHANGELOG.md).

## What changed
The **_AdswizzSDK_** v7.8.2+ keeps strong references for the given listeners, so when a listener is no longer needed it should be cleared accordingly by calling `removeListener(listener: Listener)` or `setListener(null)` depending on each case.
Those changes includes the following classes/interfaces: `AdBaseManager`, `AdManager`, `AdStreamManager`, `AdPodcastManager`, `AdVideoView`. Check the usage described in the following scenarios.


### AdManagerListener usage

```kotlin

        var adManager: AdManager? = null

        val adManagerListener = object : AdManagerListener {
            override fun onEventReceived(adManager: AdManager, event: AdEvent) {
               if (event.type == AdEvent.Type.State.AllAdsCompleted){
                   // do something when ad event is received
               }
            }
            override fun onEventErrorReceived(adManager: AdManager, ad: AdData?, error: Error) = Unit
        }

        adRequestConnection.requestAds { adManager, error ->
            this.adManager = adManager
        }

        adManager?.setListener(adManagerListener)
        adManager?.play()
        // ... other operations 

        adManager?.removeAdManagerListener() // remove listener when no longer needed


```

### AdBaseManagerListener usage

```kotlin

        var adManager: AdManager? = null

        val adBaseManagerListener = object : AdBaseManagerListener {
            override fun onEventReceived(adBaseManager: AdBaseManager, event: AdEvent) {
                // handle events here
            }
            override fun onEventErrorReceived(adBaseManager: AdBaseManager, event: AdEvent, error: Error) = Unit

        adRequestConnection.requestAds { adManager, error ->
            this.adManager = adManager
        }

        adManager?.setListener(adBaseManagerListener)

```

### AdBaseManagerAdapter usage

```kotlin

        var adManager: AdManager? = null

        val adBaseManagerAdapter = object : AdBaseManagerAdapter {
            // override any method in need 
            override fun urlsForImpression(adBaseManager: AdBaseManager, adData: AdData): List<String> { 
                return listOf("https://your.domain.for.impressions.com/impression1")
            }
        }

        adRequestConnection.requestAds { adManager, error ->
            this.adManager = adManager
        }

        adManager?.setAdapter(adBaseManagerAdapter)
        adManager?.play()
        // ... other operations

        adManager?.removeAdBaseManagerAdapter() // remove adapter when no longer needed


```

### AdStreamManager.Listener usage

```kotlin

     
        val adStreamManagerListener = object : AdStreamManager.Listener{
            override fun willStartPlayingUrl(adStreamManager: AdStreamManager, url: Uri) {
                println("adStreamManager $adStreamManager will play $url")
            }

            override fun didFinishPlayingUrl(adStreamManager: AdStreamManager, url: Uri) = Unit
            override fun didPausePlayingUrl(adStreamManager: AdStreamManager, url: Uri) = Unit
            override fun didResumePlayingUrl(adStreamManager: AdStreamManager, url: Uri) = Unit
            override fun adBreakStarted(adStreamManager: AdStreamManager, adBaseManager: AdBaseManager) = Unit
            override fun adBreakEnded(adStreamManager: AdStreamManager, adBaseManager: AdBaseManager) = Unit

            // ... other callbacks

        }
        val adStreamManager = AdswizzAdStreamManager()
        adStreamManager.addListener(adStreamManagerListener)
        adStreamManager.play("https://your.custom.stream.com")

        // ... other operations ...
        adStreamManager.stop()
        adStreamManager.removeListener(adStreamManagerListener) // remove listener when no longer needed

```
