# How to migrate to AdswizzSDK v7.12.4+

Version 7.12.4 of the **_AdswizzSDK_** introduces 1 important changes that require updates to your integration:
1. All API interface that uses Double or Long as parameter type for time related values will be replaced by Kotlin Duration type

This guide will help you upgrade your application to v7.12.4 with minimal effort. For a full list of changes, please refer to the [Changelog](Android/CHANGELOG.md).


## 1. `AdPlayer` interface
Parameter or return type `Double` or `Double?` have been replaced by `Duration` or `Duration?` type

`Old version`
```kotlin
	 
	 abstract fun getCurrentTime(): Double 
	 abstract fun getDuration(): Double?
	 abstract fun seekTo(position: Double)

```

`7.12.4 version`
```kotlin

	 abstract fun getCurrentTime(): Duration 
	 abstract fun getDuration(): Duration?
	 abstract fun seekTo(position: Duration)

```

## 2. `AdswizzAdRequest` class
Change `Long?` parameter to `Duration?`

`Old version`
```kotlin

	fun withDuration(duration: Long?) 

```

`7.12.4 version`
```kotlin

	fun withDuration(duration: Duration?) 

```
