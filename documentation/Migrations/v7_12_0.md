# How to migrate to AdswizzSDK v7.12.0+

The v7.12.0 release contains changes regarding how to add **_AdswizzSDK_** player in your project. In this guide you will find everything you need to know on how to update your application with the changes brought by **v7.12.0 and later**. For the latest changes, please visit the [Changelog](Android/CHANGELOG.md).

## What changed in 7.12.0
- `AdswizzAdRequest.Builder` changes: 
  - changed the `withZones(zones: Set<AdswizzAdZone>)` method signature to `withZones(zones: List<AdswizzAdZone>)`.
  - deprecated `.withCompanionZones(companionZones: String?)` method
  - new public method `withCompanionZoneIds(companionZones: List<String>)`
  - new public method `withCompanionZoneAliases(companionZoneAliases: List<String>)`
- **_AdswizzSDK_**'s InternalPlayer changes:
  - Added new artefact `com.adswizz:exoplayer2x` in the SDK library release. This new library provides compatibility across `com.google.android.exoplayer` versions in the range of [2.16.0; 2.19.1].
  - `com.adswizz:exoplayer-media3` artefact

### AdswizzAdRequest.Builder

#### Ad zones method changes

This change will raise a compilation error that can be easily fixed by replacing the `setOf<AdswizzAdZone>(...)` with `listOf<AdswizzAdZone>(...)` in builder method as follows: 

```kotlin
        AdswizzAdRequest.Builder() //Build the Ad Request with the needed parameters
            .withServer("SERVER_PROVIDED_BY_PIM")
//            .withZones(setOf(AdswizzAdZone("ZONEID_1"), AdswizzAdZone("ZONEID_2"))) <--- removed in 7.12.0
            .withZones(listOf(AdswizzAdZone("ZONEID_1"), AdswizzAdZone("ZONEID_2")))
            .build { adswizzAdRequest ->
//                    handle the request
            }
```
> **Note**
> The order and uniqueness of the provided **_AdswizzAdZone_** array is essential to properly retrieve the ads.

#### Companion zones method changes

The `withCompanionZoneIds(companionZoneIds: List<String>)` method enables you to provide multiple companion zone ids and a replacement for legacy `withCompanionZones(companionZones: String?)` method. 

```kotlin
        AdswizzAdRequest.Builder() //Build the Ad Request with the needed parameters
            .withServer("SERVER_PROVIDED_BY_PIM")
            .withZones(listOf(AdswizzAdZone("ZONEID_1"), AdswizzAdZone("ZONEID_2")))
//            .withCompanionZones("1243")  <--- deprecated in 7.12.0
            .withCompanionZoneIds(listOf("1234", "5678"))
            .build { adswizzAdRequest ->
//                    handle the request
            }
```
> **Note**
> Setting simultaneously `companionZoneIds` and `companionZoneAliases` in the AdswizzAdRequest.Builder will throw an Exception.
